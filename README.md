# dry-bean-classification
Machine Learning Classification using Five Models
# Dry Bean Classification – M.Tech (DSE), Machine Learning Assignment 2


## A. Problem statement
Build and compare five supervised classification algorithms to predict the class of a dry bean from numerical shape measurements. The project uses one common dataset and one stratified train/test split for a fair comparison.

## B. Dataset description
- **Dataset:** Dry Bean
- **Source:** UCI Machine Learning Repository, https://archive.ics.uci.edu/dataset/602/dry+bean+dataset
- **Task:** Multiclass classification
- **Expected dataset size:** 13,611 observations and 16 numerical predictor features, with `Class` as the target.
- **Target:** Seven dry bean varieties.
- **Preprocessing:** Numeric conversion, median imputation within each pipeline, and standardization for scale-sensitive models.
- **Split:** 80% training and 20% testing, stratified, with random state 42.

## D. Models and evaluation

The following models are trained on the same split:
1. Logistic Regression
2. Decision Tree

4. Gaussian Naive Bayes
5. Support Vector Machine (SVM)

## H. Reproducibility and notes
- A stratified 80/20 split is used with random state 42.
- All five models use the same training and test partitions.
- Median imputation is included in each pipeline to prevent preprocessing leakage.
- Weighted Precision, Recall and F1 are reported for the multiclass problem.
- AUC is calculated using weighted one-vs-rest multiclass ROC AUC.
- MCC summarizes classification quality using all classes.
